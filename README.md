# 195 Insecta & Arachnida Species Dataset

This repository hosts a curated visual dataset containing **195 species** belonging to the classes **Insecta** and **Arachnida**. Sourced automatically from [iNaturalist](https://www.inaturalist.org) (Research Grade observations), it provides between **200 and 400 photos per species** for computer vision research, fine-grained image classification, and biodiversity identification models.

---

## Dataset Overview

- **Taxonomic Scope:** 195 species across *Insecta* (insects) and *Arachnida* (spiders, scorpions, mites, etc.)
- **Volume:** 200 to 400 high-resolution images per species
- **Data Quality:** Sourced strictly from iNaturalist Research Grade observations
- **Attribution & Metadata:** Complete image metadata, original URLs, authors, and individual licenses are mapped in `licenses.json`.

---

## Download & Extraction Instructions

This dataset is split into multi-part `.rar` archives. 

1. Download all `.rar` parts into the same directory.
2. Extract the first volume (`dataset.part1.rar` or `dataset.part01.rar`) using WinRAR, 7-Zip, or `unrar`.
3. The remaining parts will automatically be extracted into the full dataset folder structure.
